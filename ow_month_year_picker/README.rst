================
 Odoo Widget
================

Creates a new field widget to make Date fields work just with Month and Years

**Table of contents**

.. contents::
   :local:

Usage
=============

Your XML form view definition could contain:

.. code-block:: XML

    <field name="month_only" widget="month"/>
    <field name="year_only" widget="year"/>
